# Pi Host-Boundary Caps, Regression Tests, and Documentation

## Architecture Context

The Pi extension is the second consumer-facing agent host. Its shared `jsonResult` currently returns uncapped `content.text` and raw `details`, so large daemon responses can bypass text caps. Pi also mirrors the MCP `eforge_extension` surface and must return compact extension-management projections by default. This plan depends on plan-01 and plan-02 so the shared helpers and MCP descriptions exist before Pi/docs parity work lands.

`packages/pi-eforge/extensions/eforge/index.ts` is over 1,000 lines; use bounded exact edits around imports, `jsonResult`, and the `eforge_extension` tool registration.

## Implementation

### Overview

Apply the shared host renderer to Pi `jsonResult`, replace raw Pi `details` with bounded metadata, compact Pi `eforge_extension` responses by default, and add synthetic giant-extension regression tests. Document the exact 12,000-character budget and update MCP/Pi user-facing guidance in sync.

### Key Decisions

1. Treat Pi `details` as host-boundary data. Return metadata such as budget, raw length, rendered length, truncated/summarized flags, and guidance instead of the original raw object.
2. Cap Pi contribution text through the shared text renderer so list/show/invoke output remains within the budget after headers.
3. Do not bump `packages/pi-eforge/package.json`; only bump the Claude Code plugin version if plugin skill files change.
4. Keep explicit raw/full detail guidance pointed at CLI `--json` or daemon/client HTTP surfaces, not default MCP/Pi tool calls.

## Scope

### In Scope

- Pi `jsonResult` `content.text` cap using the shared host-output budget.
- Pi `jsonResult` `details` replacement with bounded metadata.
- Pi `eforge_extension` compact projections by default for list/show/validate/reload/test and package/trust/new/remove actions.
- Pi contribution list/show/invoke final text cap and bounded details metadata.
- Synthetic giant-extension regression tests for Pi management and contribution outputs.
- MCP/Pi generated reference docs and extension-authoring skill guidance updated with the exact budget and compact/default vs raw/debug guidance.
- Claude Code plugin version bump if plugin files change.

### Out of Scope

- Removing full daemon discovery data.
- Removing CLI `--json` raw output for human/debug workflows.
- Bumping the Pi package version.
- Adding raw/full Pi tool output by default.
